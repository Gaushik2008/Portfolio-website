# Gaushik Kumar G — Portfolio

A responsive, dependency-free personal portfolio built with semantic HTML, CSS, and JavaScript. It includes a persistent dark/light theme, responsive navigation, and a short recording of the first portfolio pass.

## Run locally

Serve the project folder with:

```sh
python3 -m http.server 8000
```

Then visit <http://localhost:8000>.

## Publish with GitHub Pages

This site has no build step. Commit and push the repository to GitHub, then in **Settings → Pages**, choose **Deploy from a branch**, select `main` and `/ (root)`, and save. GitHub Pages will publish the HTML, CSS, JavaScript, media, and metadata files directly.
